# TrainIQ

**Планировщик тренировок, который учится тому, как тренируешься именно ты.**

Ты планируешь подходы, повторы, вес и отдых. TrainIQ прогнозирует, что ты сделаешь на самом деле: сколько повторов в каждом подходе, сколько отдохнёшь и сколько займёт тренировка. После тренировки показывает план, прогноз и факт рядом. Каждая записанная тренировка делает прогноз точнее.

## Запуск

```bash
cp .env.example .env
docker compose up --build
```

Открой http://localhost:8080. Для локальной разработки и демо-данных (`yarn seed`) смотри раздел Development в [README.md](README.md).

## Устройство

- `packages/frontend`: React, Vite, Ant Design, Tailwind, recharts, i18next (ru/en)
- `packages/backend`: Express, TypeScript, Sequelize, PostgreSQL, миграции через `yarn migrate`
- `packages/ml`: FastAPI, scikit-learn. Сервис без своей базы: бэкенд присылает историю пользователя вместе с запросом.

## Модель коротко

1. **Глобальный градиентный бустинг** учится на всех пользователях. Главный признак: вес ÷ твой недавний расчётный максимум.
2. **Признаки профиля** делают модель персональной: сколько повторов ты теряешь от подхода к подходу и какую долю плана обычно выполняешь. Считаются только по прошлым тренировкам.
3. **Личная поправка** со «стягиванием»: при малом количестве данных она около нуля, при большом равна твоей реальной средней ошибке.
4. **Отдых и темп** считаются отдельно для каждого, отдых усредняется в логарифмах.

На синтетике ошибка падает с 2.0 повтора на подход («сделаешь как в плане») до 0.68. Новый пользователь становится «понятен» модели за 3–4 тренировки. Подробнее в `packages/ml/notebooks/prototype.py`.
